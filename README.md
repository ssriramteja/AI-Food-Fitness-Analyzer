# 🍽️ AI Food & Fitness Analyzer

An end-to-end **AI-powered menu intelligence application** that converts restaurant menu images into **nutrition insights, fitness-goal recommendations, ingredient breakdowns, AI-generated food images, and an interactive chatbot (“Need Bot”)**.

This project is designed as a **real-world product**, not just an AI demo — combining **computer vision, large language models, deterministic logic, interactive UI, and conversational AI**.

---

## 🎯 Target Audience

This application is built for **multiple user groups**, making it practical and scalable:

### 🏋️ Fitness & Gym Enthusiasts
- Want to know:
  - What to eat for **weight loss**
  - Best dishes for **muscle gain**
  - Keto / low-carb friendly options
- Prefer **goal-based guidance**, not raw data

---

### 🍽️ Everyday / Normal Users
- Want transparency into:
  - Calories and macros
  - Ingredients
  - Healthiness of menu items
- No fitness jargon, just clarity

---

### 🏪 Restaurants & Food Businesses
- Add nutrition transparency to menus
- Improve customer trust
- Reduce manual nutrition analysis costs

---

### 👨‍💻 Recruiters / Interviewers / AI Learners
- Demonstrates:
  - Vision + LLM integration
  - Stateful UI design
  - Product thinking
  - Deterministic + AI hybrid logic
  - **Chatbot implementation using extracted data**
